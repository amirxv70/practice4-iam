## Файлы

| Файл | Назначение |
|---|---|
| `make_data.py` | генератор данных варианта (от преподавателя, не изменялся) |
| `store.py` | чтение и запись файлов папки `data/` (от преподавателя, не изменялся) |
| `iam.py` | задания 1–3: транслитерация и логины, новые сотрудники, проверка и генерация паролей, права должности, матрица ролей, создание учётных записей |
| `check_passwords.py` | задание 2: проверка 1000 сгенерированных паролей по политике варианта |
| `role_matrix.csv` | задание 3: матрица «должность × право», создаётся `iam.py` |
| `audit.py` | задание 4: аудит (уволенные, «осиротевшие», неактивные, лишние права, конфликты SoD) |
| `fix.py` | задание 5: исправление нарушений и журнал действий администратора |
| `logwatch.py` | задание 6: подбор пароля, входы в нерабочее время, входы в отключённые учётные записи |
| `data/` | данные варианта, создаются `make_data.py` (в репозиторий не добавляются) |

## Порядок запуска

Все команды выполняются из папки `practice4`.

```
python make_data.py            # ввести номер варианта: 5
python check_passwords.py      # задание 2: 0 паролей с нарушениями из 1000
python iam.py                  # задание 3: role_matrix.csv и учётные записи новым сотрудникам
python make_data.py            # вариант 5: вернуть исходные данные перед аудитом
python audit.py                # задание 4: все строки OK
python fix.py                  # задание 5: исправление нарушений
python audit.py --after-fix    # задание 5: все значения 0, OK
python logwatch.py             # задание 6: все строки OK
```

Используются только стандартные модули Python 3.12: csv, json, datetime, secrets, string.
